## Acceptance checks

- Six exercises with sequential Practices, one primary target and checkpoint per Practice.
- Required variable creation precedes use; parent/child Topic and flow mappings are explicit.
- Generic instructions are not the only confirmation control: flow tool is not dynamically callable and is attached only to the true branch.
- Sample cases include both categories, unknown information, unsupported input, confirmation and cancellation.
- No bank-specific data, invented official CPAll policy, live table lookup, Canvas exercise, financial analysis or Code Interpreter in learner core.
- 36 numbered teaching slides; no obsolete client-decision slides.
- Agent Builder appears only in the final overview/demo and has no learner exercise or new sample file.
- Active Day 2 material contains no legacy Teams data-retrieval module or equivalent live-table claim.
- Agenda covers 09:00–16:00 continuously: 420 minutes total, 90 minutes breaks/lunch, 330 minutes instruction/activity.
- Local links and downloadable .txt assets resolve; Markdown headings and tables render.

The package must pass local structural checks after the 14 September update: six exercises with matching targets/checkpoints, all relative links resolved, 36 teaching slides, and continuous time ranges from 09:00 to 16:00 totaling 330 instruction/activity minutes plus 90 minutes for lunch and breaks. Content review covers the parent/child variable contract, flow input/output mapping, confirmation branch, cancellation path and Agent Builder presentation-only boundary. Local structural/content validation can establish document consistency. It does not prove a flow ran, an email arrived, Knowledge indexed, or a participant could open a published agent. No client tenant changes, email sends or publication occur during authoring. Record those results during [rehearsal](./instructor-readiness-checklist.md).
