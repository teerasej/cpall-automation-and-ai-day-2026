## ลำดับเล่าเรื่องในห้อง

1. ถามเรื่องสินค้าตัวอย่างเพื่อเห็นประโยชน์ของ Knowledge
2. แจ้งปัญหาสมมติให้ Topic ถามรายละเอียดเพียงหนึ่งช่อง
3. ตรวจข้อความทวนแล้วเลือก ยืนยัน หรือ ยกเลิก
4. เมื่อเลือก ยืนยัน ให้เปิด run history และ Inbox พิสูจน์ผลส่งจริง
5. ย้ำว่าอีเมลนี้ไม่ใช่ ticket ในระบบ CPAll
